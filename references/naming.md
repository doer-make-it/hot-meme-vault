# 命名规范

## 标准命名格式

```
YYYYMMDD_平台_梗名_序号.扩展名
```

- `YYYYMMDD`：采集日期（不是梗诞生日期）
- `平台`：来源缩写（见 sources.md），如 `抖音` `B站` `微博`
- `梗名`：简短中文描述，用中横线或下划线连接多词，如 `我真无语` `打工人之怒`
- `序号`：同梗多张素材的序号，两位数字 `01` `02`...
- `扩展名`：保留原始格式

## 示例

```
20261012_抖音_我真无语_01.jpg
20261012_抖音_我真无语_02.jpg
20261013_B站_打工人之怒_01.mp4
20261015_微博_佛系青年_01.png
20261020_小红书_相亲尴尬_01.jpg
20261101_原创_哈基米日常_01.png
```

## 特殊情况

### 纯文字段子

放 `vault/texts/`，命名同规则，扩展名用 `.txt` 或 `.md`：
```
20261012_微博_我真的会谢_01.txt
```

### 视频片段

放 `vault/videos/`，命名同规则。片段若来自长视频，在 sidecar `.json` 里记 `source_url` 和 `timestamp`（精确到秒）。

### 来源不明

平台写 `未知`，并在 sidecar 标 `verified: false`。

### 梗名带特殊字符

只允许中文、字母、数字、中横线 `-`、下划线 `_`。遇到引号、问号等替换掉。

## 目录归属

按类型分目录，不按平台分（平台在文件名里已体现）：

```
vault/
├── images/    # .jpg .png .gif .webp
├── videos/    # .mp4 .mov .webm
└── texts/     # .txt .md
```

## 为什么这样命名

- 日期打头 → 按时间排序天然有序
- 平台中置 → 一眼看出来源
- 梗名中文化 → 可读，不靠编号猜内容
- 序号两位 → 同梗多张不冲突
