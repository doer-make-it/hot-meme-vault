# 采集源清单

每个源的采集方式、注意事项、命名缩写。

## 抖音 (dy)

- 采集方式：录屏 / 分享保存原图 / 链接提取（用 yt-dlp 等工具）
- 注意：竖屏 9:16，水印问题，转发注意肖像权
- 命名缩写：`抖音` 或 `dy`

## B站 (bili)

- 采集方式：yt-dlp 下载片段 / 截图 / 弹幕转文字
- 注意：可精确定位时间戳，适合做混剪素材核验
- 配合 `bilibili-material-verify` skill 做时间戳核验
- 命名缩写：`B站` 或 `bili`

## 微博 (wb)

- 采集方式：截图 / 保存图片 / 文字复制
- 注意：热搜梗时效性强，注意存原始链接防删
- 命名缩写：`微博` 或 `wb`

## 小红书 (xhs)

- 采集方式：截图 / 保存图片
- 注意：图文为主，适合"生活场景"类素材
- 命名缩写：`小红书` 或 `xhs`

## Reddit (rd)

- 采集方式：截图 / 下载图片 / 文字复制
- 注意：英文梗为主，跨文化场景用
- 命名缩写：`Reddit` 或 `rd`

## 即刻 (jk)

- 采集方式：截图 / 文字复制
- 注意：产品/互联网圈梗多，适合职场场景素材
- 命名缩写：`即刻` 或 `jk`

## 微信群/朋友圈 (wx)

- 采集方式：截图 / 保存图片
- 注意：私密性强，脱敏后入库，不存可识别的真人信息
- 命名缩写：`微信` 或 `wx`

## 自创/原创 (og)

- 自己做的或 AI 生成的
- 命名缩写：`原创` 或 `og`

## 采集通用原则

1. 原图/原视频优先存本地，链接只作元数据
2. 涉及真人露脸的标注"需授权"字段，默认不自用以外分发
3. 无法核实的来源标"未核实"，不编造作者
4. 热搜/时效梗记录"采集日期"，便于判断流行期
