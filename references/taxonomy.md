# 标签体系（六维）

每条素材打标时，从以下六个维度各取（至少一个）标签。打标结果写入 `index.json` 的 `tags` 字段。

## 1. 情绪 (mood)

素材传达的情绪基调。

`无语` `愤怒` `震惊` `治愈` `嘲讽` `自嘲` `兴奋` `emo` `尴尬` `无奈` `得意` `破防` `释怀` `焦虑` `佛系`

可扩展，遇到新的情绪就加。

## 2. 场景 (scene)

素材适用的使用场景。

`职场` `学习` `恋爱` `社交` `家庭` `网络对线` `摸鱼` `加班` `考试` `通勤` `饭局` `深夜emo` `早起` `相亲` `网购` `健身`

## 3. 类型 (type)

素材的媒体形式。

`表情包` `动图` `视频片段` `文字金句` `截图` `表情包合集` `弹幕截图` `聊天记录`

## 4. 来源 (source)

采集平台。见 `sources.md` 的缩写表。

`抖音` `B站` `微博` `小红书` `Reddit` `即刻` `微信` `原创`

## 5. 时间 (time)

- `采集日期`：入库时的日期（命名里的 YYYYMMDD）
- `流行期`：梗本身的流行时间段，如 `2026Q3`、`2026年10月`、`常青`、`未知`

## 6. 热度 (heat)

素材/梗的传播程度。

`爆款`（破圈级别，多平台刷屏） / `常青`（长期可用不过时） / `小众`（圈内传播） / `已凉`（过气但可怀旧用）

## 打标示例

```json
{
  "file": "20261012_抖音_我真无语_01.jpg",
  "tags": {
    "mood": ["无语", "自嘲"],
    "scene": ["职场", "摸鱼"],
    "type": ["表情包"],
    "source": ["抖音"],
    "time": {"collected": "20261012", "trend": "2026Q4"},
    "heat": ["爆款"]
  }
}
```

## 打标方式

两种并存：

1. **脚本解析**：`index_vault.py` 从文件名解析出日期/平台/梗名，自动填入
2. **手工补标**：在素材同目录建同名 `.json` sidecar 文件写完整 tags，脚本会合并

sidecar 示例：`20261012_抖音_我真无语_01.json`
